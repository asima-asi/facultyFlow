# FacultyFlow - College Faculty Management System

A colorful, professional and responsive college management system to manage faculty availability, students, timetable and reminders.

Live Demo: https://facultyflow.onrender.com

## ✨ Features

**Role Based Access:**
- Admin: View 10 Faculty, 200+ Students, Full Timetable, Reminders
- Faculty: My Students (62), My Profile, Timetable, Faculty Directory
- Student: Timetable 9-4, Reminders only

**Modules:**
- Dashboard with gradient cards (Total Faculty, Total Students, Available Now, In Class)
- Timetable 9 AM - 4 PM (Mon-Sat) with color pills
- Faculty Directory - 10 Faculty with status (FREE NOW / IN CLASS / ON LEAVE)
- Student Management - Unique names, no repeat
- Reminders System
- Professional Secure Login

**Design:**
- Colorful gradient login (purple-pink)
- Gradient dashboard cards (blue, green, yellow, red)
- Fully responsive
- No non-professional words - 100% professional UI
